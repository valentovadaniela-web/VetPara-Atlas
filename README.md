# Overview

VetPara Atlas is a long-term open project focused on creating a modern veterinary parasitology diagnostic information system.

The project combines:

- structured diagnostic database
- high-quality microscopy image atlas
- laboratory knowledge base
- intelligent diagnostic tools
- future AI-assisted identification

The goal is to build a professional platform suitable for:

- Veterinary diagnostic laboratories
- Veterinary practitioners
- Universities
- Veterinary students
- Researchers
- Teaching institutions

---

# Vision

The project is designed as a **Data First** application.

Unlike a traditional image atlas, VetPara Atlas stores structured diagnostic knowledge that can later be used for:

- advanced filtering
- differential diagnosis
- laboratory workflows
- AI image recognition
- automated measurements
- educational tools

---

# Main Features

## Diagnostic Atlas

Comprehensive database of veterinary parasites.

Including:

- Protozoa
- Nematoda
- Cestoda
- Trematoda
- Arthropoda
- Blood parasites

---

## Image Gallery

High quality laboratory photographs with metadata.

Each image contains:

- diagnostic object
- host
- sample
- magnification
- diagnostic method
- laboratory
- author

---

## Diagnostic Expert

Future rule-based expert system allowing identification based on:

- host
- sample
- morphology
- measurements
- shell
- colour
- diagnostic method

---

## AI Roadmap

Future AI modules include:

- image recognition
- automatic micrometry
- OCR
- differential diagnosis
- explainable AI
- laboratory assistant

# AI Principles

Artificial Intelligence is intended to **assist**, not replace, veterinary professionals.

Every future AI module must be:

- explainable
- transparent
- evidence-based
- human-supervised

The final diagnostic decision always belongs to the laboratory diagnostician or veterinarian.
